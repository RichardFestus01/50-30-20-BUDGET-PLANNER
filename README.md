This is a clean and responsive web-based budget planner designed to help you manage your personal finances using the popular 50/30/20 rule. The application is built with plain HTML, JavaScript, and styled with Tailwind CSS.

Key Features:
Dynamic Budgeting: Automatically calculates your budget based on the 50% (Needs), 30% (Wants), and 20% (Savings) rule from your total income.
Multiple Income Streams: Add and track various sources of income.
Comprehensive Expense Tracking: Log your expenses and categorize them as Needs, Wants, or Savings contributions.
Real-time Overview: Instantly see your remaining balance and spending progress for each category with dynamic progress bars.
Multi-Currency Support: Choose from a wide range of world currencies to manage your budget in your local currency.
Data Persistence: Your financial data is automatically saved to the browser's local storage, so it persists even after you refresh the page.
CSV Export: Download a complete report of your income, expenses, and budget summary at any time.
User-Friendly Interface: A simple, intuitive, and fully responsive design.

Technologies Used:
HTML5
Tailwind CSS
JavaScript (ES6+)
This project is a great example of a practical, client-side application built with modern web standards.
